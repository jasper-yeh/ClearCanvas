# Changelog

All notable changes to the project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

While the major version is 0, the versioning scheme is actually `0.<increment>.<feature>`:
the minor number is the development increment, and the patch number is incremented for each
feature or fix within that increment.
